# Firmware-Platzhalter

ESP-IDF-App startet hier, sobald Lab-/Hub-Gerüst steht.

Geplante Komponenten (später unter `../components/`):

- `hub_client` — Register + OTA-Pull (esp-hub)
- `ota_manager` — NVS-Defer
- `pump` — PUMP UART/CDC (später WLAN)
- `msc_gadget` — TinyUSB MSC + virtuelles FAT
- `stream_buffer` — MP3-Vorpuffer

Aktuell: absichtlich **keine** kompilierbare Firmware (Planung zuerst).
