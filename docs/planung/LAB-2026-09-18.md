## Testergebnisse

### Menü / 4-Slot-Paging

| Check | Ergebnis |
|-------|----------|
| Root Seite 0 | Favoriten, Quellen, Stop, **Mehr… (+3)** |
| Root Seite 1 | **Audio, Verbindungen, System**, Seite 1 |
| Quellen Seite 0–2 | FM/DAB → Webradio/Spotify/Scanner → **Bibliothek** |
| Audio-Paging | Auto/BT → Klinke/HDMI/Lauter… |
| Spotify erreichbar | ja (Ordner + An/Aus) |

**Fazit:** Mit Soft-Paging sind zuvor abgeschnittene Root-/Quellen-Einträge über ESP erreichbar. Physisch weiter **4 MSC-Slots**.

### Bibliothek / lokale MP3

| | |
|--|--|
| Aktion | `Alle: Musik` / `local_play:…` |
| Pi now | Diamond On A Landmine · Billy Talent |
| `library_file` | `/home/pidrive/Musik/08_-_Diamond_On_A_Landmine.mp3` |

## Offene Folgepunkte

1. Physisch **>4 FAT-Dateien** (FAT neu erzeugen) statt nur Soft-Paging  
2. Spotify/Pulse → MP3 für USB-Pfad  
3. ID3-Titel bei Library aus Tags statt Aktionslabel nachziehen (Timing)  
4. Host-Player liest MSC-Datei durchgehend (`dd`/`mpv` auf Stick)  
5. NBT Cover-Cache Feldtest
